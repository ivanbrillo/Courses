Cost Management

2. Estimate Costs

The process of developing an approximation of the monetary resources needed to complete project work

3. Determine Budget

The process of aggregating the estimated costs of individual activities or work packages to establish an authorized cost baseline

  • A project budget includes all the funds authorized to execute the project
  • The cost baseline is the approved version of the time-phased (break down) project budget that includes contingency reserves, but excludes management reserves
    • Contingency reserves are funds set aside to cover identified risks (for example, you know there’s a chance equipment might cost more if shipping delays occur)
    • Management reserves are extra funds set aside for unforeseen work or “unknown unknowns” (things you can’t specifically predict)

4. Cost Control

The process of monitoring the status of the project to update the project costs and manage changes to the cost baseline

  1. WBS (Work Breakdown Structure):
    • Breaks down the project scope into manageable work packages.
    • Each work package defines a specific set of deliverables or work.
  1. OBS (Organizational Breakdown Structure):
    • Represents the organization or resources responsible for executing the project.
    • Defines who is responsible for what work.
  1. Cost Account:
    • The intersection between a WBS element (what work) and an OBS element (who does the work).
    • It’s a control point where budget, actual cost, scope, and schedule are tracked and integrated

Earned Value Analysis

Earned Value Management is a process that uses earned value as the primary tool for integrating cost, schedule, technical performance management, and risk management

  • EV = how much of the project’s authorized budget should have been spent for the work actually completed
  • emphasizes prevention over cures by identifying and resolving problems earlier

EVM systematically brings together:

  • Cost Management (tracking AC vs. BAC),
  • Schedule Management (tracking EV vs. PV),
  • Technical Performance (measuring tangible technical deliverables),
  • Risk Management (incorporating reserve analyses and risk‑adjusted forecasting)
