  1. torch.utils.data.Dataset follows the map python data model. You have to implement the methods:
    1. len(self): returns the number of data points
    1. getitem(self, i): returns the i-th data point
  1. torch.utils.data.IterableDataset follows the iterable python data model. You have to implement the method:
    1. iter(self): returns an iterable over the data points
    1. Can be easly implemented by making the class itself an iterable by returning self with iter() and implementing __next__()

The class torch.utils.data.DataLoader combines a dataset and a sampler, and provides an iterable over the given dataset

  • dataset
  • batch_size
  • shuffle
  • sampler
  • num_workers

The fundamental building block of PyTorch models is the torch.nn.Module class.

  • Any attribute of a Module that is a torch.nn.Parameter is automatically included in the parameters list of that module.
  • All parameters within these sub-modules are seamlessly aggregated into the parameters list of the containing module.
    • linear, conv, …

The most important methods of a torch.nn.Module are:

  1. init(self) → Constructor method where you define the attributes (parameters and sub-modules) of your module.
    1. Remember to call the parent constructor with super().init()
  1. forward(self, input) → Crucial method where the actual computation of the module occurs.
  1. parameters(self) → Returns an iterator over module parameters.
    1. Parameters are tensors that are automatically optimized during training.
  1. to(self, device) → Moves the module to the specified device (CPU or GPU).
x = torch.tensor([[1.], [2.], [3.], [4.]])
y = torch.tensor([[3.], [5.], [7.], [9.])

dataset = TensorDataset(x, y)
dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

model = torch.nn.Linear(1, 1)
loss_fn = torch.nn.MSELoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

for _ in range(1000):
    for xb, yb in dataloader:
        optimizer.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward()
        optimizer.step()
