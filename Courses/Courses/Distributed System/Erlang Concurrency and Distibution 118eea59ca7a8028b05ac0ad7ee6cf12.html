Erlang Concurrency and Distibution

The fondamental computational unit is an actor, identified by an ID . Every computation involves at least one actor.

  • Actors shares nothing with others actors
  • Actors can communicate with asynch message passing

When an actor receive a message it can concurrently:

  1. send a finite number of messagges to other
  1. create a finite number of new actors
  1. designate the behaviour to be used for the next message

Actors are called processes

  1. Create a process: spawn(…)
  1. Sending messagges: PID!message
  1. Receive messagges: receive … end
