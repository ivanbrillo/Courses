Edge Detection

Edges are pixels located in significant local changes in the intensity of an image and are important features for analysing images

An edge detector is an algorithm that produces a set of edge points S from a input image

This approach tends to generate too many edge points

  • A better approach would be to find pixels that have a local maximum in the gradient magnitude, and consider them as edge points
  • A pixel being a local maximum in the gradient magnitude corresponds to a pixel with a zero-crossing in the second derivative

We need to find a way to suppress the high frequency noise before computing the discrete derivative
