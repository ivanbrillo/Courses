Prompt

A prompt is a specific text sequence provided as input to a large language model

  • Since it is used to bootstrap the language model generative behaviour, it can be interpreted as a learning signal → it will influence the final probability distribution

The behaviour of a large language model to use its prompt as a learning signal is called in-context learning, sometimes more efficient than fine-tuning billions of parameters

  • in-context learning requires an adequate prompt, and finding good prompts is the goal of prompt engineering
  • Prompt engineering encompasses techniques for eliciting desired behaviours from LLMs through input design rather than parameter modification

A template is a particular prompt with some fixed text and some free text

  • The fixed text depends on the task, and it is called instruction
  • “Answer the following question: [free text]”

Incorporating examples into a template can significantly enhance the quality of the prompt

  • These input texts, referred to as demonstrations, serve as guiding
    example text

Different types of prompt:

  1. Zero-shot → feed the task text to the model and ask for results
  1. Few-shot mode → enables in-context learning by providing demonstrations in the prompt to steer the model to better performance
    • The demonstrations serve as conditioning for subsequent examples where we would like the model to generate a response
  1. Chain-of-Thought (CoT) → allows complex reasoning capabilities through intermediate reasoning steps provided in demonstrations, that are logically linked and interposed with model responses

It’s important not to give the model too much freedom in the prompt

  • e.g. in IR: given this query [], and this documents [], provide a relevant judgement, using the following scale [5: best …., 4: ….], provide a single number from 1 to 5

LLMs can generate new content that is false (hallucinations), or that can be considered offensive or harmful

  • to address both we use fine-tuning

After the pre-training (using web content) [the output of the process is a base LM], we need a second step to make it confortable with prompts [instruct LM]

  1. Instruction tuning or supervised fine-tuning (SFT), requires a task-specific dataset including instructions and filled prompts to specialise the large language model on the specific downstream task and its instructions
    • loss is still CE
    • Now we are heavily conditioning our model to take into account the presence of specific instructions as preconditions to text generation
      • e.g. what is the color of the Napoleon’s white horse?
        • base LM: race
        • instruct LM: white

    Parameter efficient fine-tuning (PEFT) → keep the LLM weights fixed and add some modules to finetune

    • This makes finetuning affordable with moderate computational power
    • The most famous implementation is called low-rank adaptation (LoRA) W′=W+ΔWW' = W + \Delta WW′=W+ΔW﻿
      • where WWW﻿ are the frozen LLM weights and ΔW\Delta WΔW﻿ the learned parameters using a low-rank approximation of the matrix
