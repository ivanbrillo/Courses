Probabilistic Information Retrival

Thus far, the queries have all been boolean. Useful for precise queries

  • all patents relevant to a new patent
  • all legal docuements relevant to a case
  • all pdfs of a given topic
  • spam search containing specific words

Most users don’t want to scan through 1000s of results

  • It takes a lot of skill and time to come up with a query that produces a manageable number of document [AND gives too few, OR gives too many]

Both the user need and the document relevance to a query is uncertain

  • We rank the top-k documents returned by P(relevant ∣ document, query)P(\text{relevant } | \text{ document, query})P(relevant ∣ document, query)﻿

Hypotesis probabilistic retrieval model:

  1. A user has an information need, that is encoded as a textual query (not necessarily complete)
  1. A user expresses a relevance judgement on a given document for a given information need expressed as a query [strong assumption]
    • typically not explicitily observable
  1. A relevance judgment is a document property depending uniquely on the information need
    • independent from other documents
    • independent from other information needs
    • binary: relevant or non-relevant

Probability Ranking Principle

Probability Ranking Principle (PRP): If a reference retrieval system’s response to each query is a ranking of the documents in the collection in order of decreasing probability of usefulness to the user who submitted the request, where the probabilities are estimated as accurately as possible on the basis of whatever data has been made available to the system for this purpose, then the overall effectiveness of the system to its users will be the best that is obtainable on the basis of that data.

  • Usefulness is measured as relevance of a document to a query
  • Relevance RRR﻿ is a binary random variable with possible values r=0,1r = 0, 1r=0,1﻿
  • Query QQQ﻿ is a random variable with generic value qqq﻿

We denote P(R=r∣Q=q,D=d)P(R=r | Q=q, D=d)P(R=r∣Q=q,D=d)﻿ with P(r∣q,d)P(r|q, d)P(r∣q,d)﻿ [3 random variables]

  • Specific to an information need of a single specific user
  • Rk∈{0,...,k}R_k \in \{0, ..., k\}Rk​∈{0,...,k}﻿ is a random variable denoting the number of relevant documents retrieved given a query
  • The overall effectiveness is measured by E[Rk]\mathbb{E}[R_k]E[Rk​]﻿
