Variable-Byte Code

In practice the computer memory is allocated in chunks of bytes, not bits.

  • We may focus on codewords that are byte-aligned rather than bit-aligned → better cache and decoding speed
  • The variable-byte code VB(x)VB(x)VB(x)﻿ computes the binary representation bin(x)bin(x)bin(x)﻿ of xxx﻿
  • For each byte:
    • 7 bits, called data bits, are allocated for the representation of xxx﻿
    • 1 bit, called control bit is used to signal the continuation/end of the stream of bytes.
