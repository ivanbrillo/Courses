Text Processing

Encodings

ASCII → 7 bit representation

  • The eighth bit is filled with 0 for padding
  • Problem with other alphabets like Cyrillic

Then Unicode is used (not a character encoding)

  • The Unicode Standard defines a codespace, a set of numerical values ranging from 0 through 10FFFF
  • The number assigned to a character is called a code point
  • A code point is denoted by “U+” following by a hexadecimal number from 4 to 8 digits long

Code points are not representations of characters as sequences of bytes

  • For example, the code point U+0C36 is not a sequence of the bytes 0x0C and 0x36 → it is not a character encoding scheme

In UTF-8 characters are encoded with anywhere from 1 to 4 bytes → bytes varies for characters

  • All ASCII characters are encoded within the 7 least significant bits of a byte whose most significant bit is 0
  1. The number of leading 1 bits in the start byte tells you how many bytes the whole character uses → self-synch (no need to start reading from start to recover)
  1. Files and strings that contain only 7-bit ASCII characters have the same encoding under both ASCII and UTF-8
    • No ASCII byte can appear as part of any other character
  1. Prefix Free encoding

Tokenization

A corpus is a computer-readable collection of text or speech (eg. collection of web pages), also known as document collection

  • An element of a corpus is referred as a document

  1. Token: an instance of a sequence of characters in some particular document that are grouped together as a useful semantic unit
  1. Vocabulary: the set of all tokens appearing in a given corpus
  1. Term: an element of the vocabulary

  • Vocabulary size grows faster than the square root of the number of tokens

Tokenisation is the task of segmenting documents into words

Space-based tokenisation (for languages that use space characters between words)

  • Segment off a token between instances of spaces (and/or special chars) and maybe transformed everything to lowercase

Issues:

  1. Can't just blindly remove punctuation (Ph.D., $4.5, 01/02/25, #forcio, mails)
  1. Clitic: a word that doesn't stand on its own (we’re, don’t)
  1. multiword expressions like New York

Word normalization is the task of putting words/tokens in a standard format

  • U.S.A or USA, Nicola or nicola, I’m or I am

Case folding: reduce all letters to lowercase (but US != us)

Lemmisation: represent all words as their lemma (their shared root, eg. plurals)

  • Lemmatisation is done by Morphological Parsing
  • Morphemes: the small meaningful units that make up words
    "unhappiness" → un- (not) + happy (stem) + -ness (state of)
    • Stems: The core meaning-bearing units
    • Affixes: Parts that adhere to stems, often with grammatical functions (prefixes/suffixes that modify meaning)

Porter Stemmer: the most common algorithm for stemming english (1980s)

Based on a series of rewrite rules run in series. There are five phases done in sequence:

  1. SSES → SS (caresses → caress)
  1. IES → I (ponies → poni)
  1. SS → SS (caress → caress)
  1. S → (cats → cat)

The stemming process is irreversible, i.e., we can’t recover the original token from its stemmed token

Stop words are some extremely common words that would appear to be of little value in a task

  • Filters out articles, prepositions, conjunctions (e.g., the, am, and) that have very low discrimination values for retrieval purposes
  • Reduces the size of the indexing data structures considerably

They could be found with:

  1. List look-up (stopword lists)
  1. Frequency information from other collections
  1. frequency analysis (all terms occurring in more than 80% of documents removed)

NB: can be important in combinations, example: “to be or not to be”

Lemmatization is a text processing technique in Natural Language Processing (NLP) that reduces words to their base or dictionary form (lemma) by considering context, ensuring the result is a real word, unlike stemming which just chops off endings.
