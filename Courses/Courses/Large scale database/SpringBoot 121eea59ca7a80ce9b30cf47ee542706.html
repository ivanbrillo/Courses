Entity

model package → automatically mapped to a table in a DB

@Data     // lomlock to generate getters and setters
@Entity   
@NoArgsConstructor
@AllArgsConstructor
public class Event {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

		@Column(updatable = false)           // cannot be updated once created
    private String title;               

    @Column(columnDefinition = "TEXT")   // Column with TEXT type and 
    private String description;          // not the default VARCHAR

		@NotNull(messagge = "frocio")        // useful for data validation
    private LocalDate date; 
    
    @OneToOne                            // 1:1 relationship
    @JoinColumn(name = "user_id")
    private User user;
      
}

Repository

  • The JpaRepository interface provide basic CRUD (Create, Read, Update, Delete) operations for entities.
  • It provides key methods such as save(), findById(), findAll(), and deleteById() etc.
  • Can create automatically custom queries if you follow some name conventions.
  • If I have different languages then SQL I can just change the interface JpaRepository
public interface PersonRepository extends JpaRepository<Person, Long> {

  List<Person> findByFirstNameEndsWithIgnoreCase(String firstNameEnd);

	@Query("SELECT p FROM Person p WHERE p.firstName LIKE %:firstNamePart%")
  List<Person> searchByFirstName(@Param("firstNamePart") String firstNamePart);

}

Service

  • The service class is designed to contain business logic. It's where you define operations related to your application's core functionalities, such as processing data, interacting with repositories, and applying business rules.
  • Spring will automatically detect this class during component scanning and create a bean for it. This enables dependency injection and allows the class to be injected into controllers or other components.
@Service
@RequiredArgsConstructor       // useful for automatic dependency injection 
public class EventService {
    private final EventRepository eventRepository;

    public List<Event> getAllEvents() {
        return eventRepository.findAll();
    }

    public void deleteAllEvents() {
        eventRepository.deleteAll();
    }
}

Controller

  • The controller class is responsible for processing incoming HTTP requests, delegating actions to the service layer, and returning appropriate HTTP responses. It acts as the intermediary between the client (e.g., a web browser or mobile app) and the backend logic.
  • Define the end-points of the API
@RestController
@RequestMapping("/api/events")        // only parts of the request
@RequiredArgsConstructor
public class EventController {
    private final EventService eventService;

    @GetMapping 		// /api/events?username=Fro
    public List<Event> getAllEvents(@RequestParam String username) {
        return eventService.getAllEvents();
    }

    @PostMapping
    @ResponseStatus(HTTP.ACCEPTED)
    public Event createEvent(@Valid @RequestBody Event event) {  // automatic validation
        return eventService.createEvent(event);
    }
    
    @PutMapping("/{id}")
    public ResponseEntity<Event> updateEvent(@PathVariable Long id, @RequestBody Event event) {
        return ResponseEntity.ok(eventService.updateEvent(id, event));
    }
}

Data Validation

@ControllerAdvice       // in all controllers
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<String> handleResourceNotFoundException(ResourceNotFoundException ex) {
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(ex.getMessage());
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<String> handleGenericException(Exception ex) {
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
                             .body("An unexpected error occurred: " + ex.getMessage());
    }
}

Configuration

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .csrf(csrf -> csrf.disable()) // Disable CSRF for simplicity
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/api/events/admin/**").hasRole("ADMIN") // Admin-only access
                        .requestMatchers("/api/events/**").permitAll() // Public access for event endpoints
                        .anyRequest().authenticated() // All other requests must be authenticated
                )
                .httpBasic(withDefaults()); // Modern httpBasic() replacement with lambda style

        return http.build();
    }

    public UserDetailsService userDetailsService(PasswordEncoder passwordEncoder) {
        // In-memory user store with admin and normal user roles
        UserDetails admin = User.builder()
                .username("admin")
                .password(passwordEncoder.encode("adminpassword"))
                .roles("ADMIN")
                .build();

        UserDetails user = User.builder()
                .username("user")
                .password(passwordEncoder.encode("userpassword"))
                .roles("USER")
                .build();

        return new InMemoryUserDetailsManager(admin, user);
    }
    
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(); // Using BCrypt for password encoding
    }
}
